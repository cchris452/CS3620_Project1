# CS3620_Project1
A choose your own adventure Python App.
Project Requirements
An Entertaining Adventure Story (No lorem Ipsum)
Use of Functional and/or Object-Oriented Programming.
Use of Control Structures, Functions, File Handling 
(Ex: Can choose a specific file to load to make a decision 
or write the user's adventure to a file), and Python Types.
A Minimum of 10 User Decision Points.
A Minimum of 20 Narratives.
